# CompactThreadPool

A modern C++20 thread pool implementation focusing on simplicity and efficiency.

![Language](https://img.shields.io/badge/language-C%2B%2B20-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## Features

- 🚀 Header-only library
- 💪 Modern C++20 implementation
- 🛡️ Exception safe task handling
- ⏰ Task timeout control
- 🔄 Wait for all tasks completion
- 📊 Thread pool status monitoring
- ✨ Type trait utilities for parameter safety

## Requirements

- C++20 compiler support
- pthread support
- Linux environment (tested)

## Installation

It's a header-only library. Just include the header file:

```cpp
#include "pools.hpp"
```

## Quick Start

```cpp
#include "pools.hpp"
#include <iostream>

int main() {
    // Create thread pool with 4 threads
    Compact::ThreadPools pool(4);

    // Submit a task
    auto future = pool.enqueue([]() {
        return 42;
    });

    // Get result
    std::cout << "Result: " << future.get() << std::endl;

    return 0;
}
```

## Advanced Usage

### Task with Timeout

```cpp
using namespace std::chrono_literals;

auto status = pool.enqueue_timeout(100ms, []() {
    // Long running task
    return 42;
});

if (status == std::future_status::timeout) {
    std::cout << "Task timed out!" << std::endl;
}
```

### Wait for All Tasks

```cpp
pool.wait_all(); // Blocks until all tasks complete
```

### Monitor Pool Status

```cpp
auto status = pool.get_statue();
std::cout << "Working threads: " << status.working_threads << "\n"
          << "Pending tasks: " << status.pending_tasks << "\n";
```

## Implementation Details

- Uses `std::packaged_task` for task wrapping
- RAII-style resource management
- Lock-free atomic operations where possible
- Conditional variable based synchronization
- Custom deleters for proper resource cleanup
